怎么用：先选一个框架（下面会写清每个字母是什么意思）。教练按字母一步步带你走：先抛一个大问题，你在框里写答案、点「继续」，它读你写的、顺势追下一问，并在进入新阶段时点明现在问的是哪个字母。
接了 API 时（如在 claude.ai 里）追问是量身生成的；没接时（如部署到 Vercel）用预设的追问阶梯。想要更深的复盘，点右下角 导出，把整份记录复制贴给 Claude 即可。
